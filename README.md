# Java Day 63 – Loan EMI & Amortization Calculator

## Project Description
A Java application that calculates monthly loan EMI, total interest, total repayment, and a month-wise loan repayment schedule.

## Features
- Accepts loan amount, interest rate, and duration.
- Calculates monthly EMI.
- Calculates total interest.
- Calculates total repayment.
- Generates a month-wise amortization schedule.
- Exports the schedule to a CSV file.

## Technologies Used
- Java
- Object-Oriented Programming
- Classes and Objects
- ArrayList
- File Handling
- Mathematical Calculations

## Project Files
- `Main.java` – Main application.
- `loan_schedule.csv` – Generated repayment schedule.

## How to Run
1. Compile using `javac Main.java`.
2. Run using `java Main`.
3. Enter the loan details.
4. View the repayment schedule.
5. Open `loan_schedule.csv` in Excel or another spreadsheet application.

## Learning Outcome
Learned how to apply OOP, store payment records using ArrayList, perform EMI calculations, and export financial data to CSV.
